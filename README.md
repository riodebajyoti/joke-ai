# Joke AI

A local browser joke app made by Rio.

## Run

Open `joke_AI.py` in IntelliJ and click Play, or run:

```sh
python3 joke_AI.py
```

You can also open `joke_ai_browser.html` directly in a browser.

## Features

- Random knock-knock and regular jokes
- Interactive replies and answer guessing
- Type `why` or `what` to reveal regular-joke answers
- Remembers your name in browser storage

No additional Python packages are required. The jokes come from a built-in collection.

Personal profiles, virtual environments, IDE settings, and other lesson files are excluded from Git.
